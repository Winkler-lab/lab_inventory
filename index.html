Backup inventory
Download a full snapshot of the inventory data for safe keeping.
The backup is saved as a JSON file. JSON is best for this because it preserves the full structure of the inventory, including projects, experiments, protocols, materials, legacy tissue records, cell lines, mice/PDX records, activity log entries, and all custom fields.
Recommended: download a backup after major inventory updates, before deleting many records, and at least once per month. Store the file somewhere outside the app, for example in ownCloud or a lab shared drive.
